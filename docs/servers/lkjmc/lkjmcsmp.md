# lkjmcsmp

## 概要

`lkjmcsmp` は、`lkjmc` 内で動くサバイバルサーバーです。通常のサバイバルに、TP機能、経済、チーム、実績、GUIを足して、初参加者と継続参加者の両方が遊びやすい状態にしていきます。

## 入れていきたい要素

`lkjmcsmp` リポジトリのドキュメントを参考に、次のような要素を整理しています。

- その場限りのジエンド（ディメンション）
- GUI中心のメニュー
- ポイント経済
- より充実したショップ
- 実績と報酬
- プレイヤーのランキング情報
- HUD、多言語対応、ホットバー導線
- 一時ディメンションやイベント用拡張
