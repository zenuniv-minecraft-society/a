# lkjmc Entrypoints

## Canonical Address

`lkjmc` の告知で使う基準アドレスは `lkjsxc.com` です。

- Minecraft: Java Edition: `lkjsxc.com` (`25565/tcp`)
- Minecraft: Bedrock Edition: `lkjsxc.com` (`19132/udp`)
- Simple Voice Chat: `lkjsxc.com` (`24454/udp`)

## Alias

`mc.lkjsxc.com` はDNS上 `lkjsxc.com` と同じ公開IPへ向いています。ただし、MOTD、Simple Voice Chat、Geyser、TABなどの現行設定は `lkjsxc.com` を基準にします。

## Version Policy

READMEに固定のMinecraftバージョンを書きません。Velocity、Geyser、ViaVersion、ViaBackwardsの更新で対応範囲が変わるためです。

参加できない場合は、まずDiscordのお知らせとサーバーリスト表示を確認してください。
