# lkjmc Network

## 構成

`lkjmc` では公開入口をVelocityに寄せています。VelocityがMinecraft: Java Editionのproxy入口になり、GeyserとFloodgateでMinecraft: Bedrock Editionからの参加も受けます。

## 公開している要素

- `lkjsxc.com`: `lkjmc` の告知で使う基準ドメイン
- `hub`: 入口や中継として扱うバックエンド
- `lkjmcsmp`: `lkjmc` 内のサバイバルSMP
- event backends: 必要に応じて増減する企画用サーバー
