# lkjmc

`lkjmc` は、サークルで使えるMinecraftサーバーの一つです。管理者のユーザー名は `lkjsxc` です。現在はVelocityを入口に、Minecraft: Java Edition、Minecraft: Bedrock Edition、Simple Voice Chat、`lkjmcsmp` バックエンドを提供しています。

## ページ

- [entrypoints.md](entrypoints.md): 各エディションとSimple Voice Chatの接続先
- [lkjmcsmp.md](lkjmcsmp.md): サバイバルSMPの目的と機能方針
- [voice-chat.md](voice-chat.md): Simple Voice Chatの公開設定
- [network.md](network.md): Velocity中心の公開ネットワーク像
- [live-state.md](live-state.md): 読み取り確認の公開用要約

## 接続先

- Minecraft: Java Edition: `lkjsxc.com`
- Minecraft: Bedrock Edition: `lkjsxc.com:19132`
- Simple Voice Chat: `lkjsxc.com:24454/udp`

`mc.lkjsxc.com` もDNS上は同じ公開先を向きますが、告知とサーバー表示の基準は `lkjsxc.com` です。
