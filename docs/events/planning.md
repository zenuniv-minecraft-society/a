# Event Planning

## 告知に入れること

イベント告知には次を含めます。

- 日時
- 参加場所
- 必要なMinecraftエディション
- 必要なMinecraftバージョン
- 必要なmodやリソースパック
- 途中参加の可否
- 目的
- 終了予定または目安

## 企画時の確認

- 初参加者が接続先を見つけられるか
- Minecraft: Bedrock Edition参加者に制限があるか
- Simple Voice Chatが必要か
- 荒らしや事故への一次対応者がいるか
- イベント後に残す記録の置き場所が決まっているか

## 終わったあと

企画後は短くてもよいので、[activity timeline](../activity/timeline/README.md) へ次を残します。

- 何をしたか
- 参加規模
- よかった点
- 次に直す点
- 関連ページへ反映する内容
