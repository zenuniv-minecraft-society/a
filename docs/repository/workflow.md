# Workflow

## 基本の流れ

1. 変更したい内容に一番近いREADMEを読む。
2. 既存の子ドキュメントに入るならそこを更新する。
3. 入る場所がない場合は、先に親READMEへ新しい置き場所を作る。
4. 親README、子ドキュメント、必要ならroot READMEを同じ変更で揃える。
5. `./scripts/verify.sh` を実行する。

## 変更の順番

1. 変更対象のREADMEを読む。
2. 親READMEと子ドキュメントを同じ変更で更新する。
3. 残すべき活動なら `docs/activity/timeline/` の日付ディレクトリへ記録する。
4. `./scripts/verify.sh` を実行する。

置き場所や書き方は [writing-policy.md](writing-policy.md) を見ます。
