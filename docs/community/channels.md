# Channels

## Slack

大学内からこのサークルを発見するための場所です。

- 新規参加者の入口
- 重要告知の共有
- Discordやイベントへの誘導

## Discord

普段の活動拠点です。

- サーバーのお知らせ
- イベント進行
- VCと雑談
- サーバー不具合の共有
- 運営相談
- Minecraft内で説明しきれない補足

## GitHub

ほとんどの情報を記録しています。

- 公開README
- 活動記録
- タイムライン
- 暗黙知
- 編集者向けの補足

## 情報の優先度

Discord、Slack、GitHubで情報が食い違う場合、Discordを最優先とします。
