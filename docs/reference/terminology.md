# Terminology

Minecraft関連の用語です。

## 用語

- `Minecraft: Java Edition`: MinecraftのJava Editionを指す正式寄りの表記。
- `Minecraft: Bedrock Edition`: MinecraftのBedrock Editionを指す正式寄りの表記。
- `Simple Voice Chat`: 近接ボイスチャット機能のmodまたはplugin名。
- `Velocity`: Minecraftサーバーproxy。
- `Geyser`: Minecraft: Bedrock Edition から Minecraft: Java Edition サーバーへ接続するためのソフト。
- `Floodgate`: Geyserと組み合わせ、Minecraft: Bedrock EditionアカウントでMinecraft: Java Editionサーバーへ入りやすくするplugin。
- `ViaVersion`: 新しいJava Editionクライアントから古いサーバーへ接続しやすくする互換plugin。
- `ViaBackwards`: 古いJava Editionクライアントから新しいサーバーへ接続しやすくする互換plugin。
- `Folia`: Paperのforkで、regionized multithreadingを持つサーバー実装。
